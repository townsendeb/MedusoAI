# Meduso AI

SaaS platform that helps local businesses identify unhappy customers before they leave negative reviews or stop returning.

## Quick start

```bash
npm install
cp .env.example apps/web/.env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). For Inngest and Edge Functions, see the [developer guide](./docs/README.md).
